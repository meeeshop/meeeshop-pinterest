# Video Integration Guide — Post Videos to Pinterest Daily

The Pinterest automation now supports **3 video sources**:
1. **Local videos** from `meeeshop-youtube` repo (fastest)
2. **YouTube channel** videos (automatic)
3. **Product images** (fallback)

---

## Video Sources Explained

### 1. 🎬 Local Videos (meeeshop-youtube repo)

**Where to store:**
```
meeeshop-youtube/
├── videos/          ← Put videos here (PRIMARY)
├── output/          ← Or here
├── shorts/          ← Or here
├── generated/       ← Or here
├── rendered/        ← Or here
└── exports/         ← Or here
```

**Supported formats:**
- `.mp4` (recommended)
- `.webm`
- `.mov`
- `.avi`
- `.mkv`

**Setup:**
1. Generate videos using `meeeshop-youtube/youtube_shorts.py` or manually
2. Place in any directory above
3. Script automatically finds & picks them

**Example:**
```powershell
# Videos generated by youtube_shorts.py go to:
C:\Users\USER\Downloads\Shopify_Claude\meeeshop-youtube\videos\

# Or manually place them:
C:\Users\USER\Downloads\Shopify_Claude\meeeshop-youtube\shorts\summer_dress_showcase.mp4
```

### 2. 📺 YouTube Channel Videos

**How it works:**
1. Script reads `YOUTUBE_CLIENT_ID` & `YOUTUBE_CLIENT_SECRET` from `meeeshop-youtube/.env`
2. Fetches latest videos from your channel
3. Picks random recent video (last 30 days)
4. Uses thumbnail + metadata

**Requirements:**
- YouTube API enabled in Google Cloud
- Client ID & Secret in `.env` ✓ (already in your setup!)
- Channel public

**What gets picked:**
```
Video from YouTube Channel
├── Title
├── Description
├── Thumbnail image
├── Upload date
└── Link to YouTube
```

**How it posts:**
- Uses thumbnail image for pin
- Title from YouTube title (AI-optimized)
- Description from YouTube description (AI-optimized)
- Link points to YouTube video

### 3. 🖼️ Product Images (Fallback)

**Fallback logic:**
- If no local videos found
- If no YouTube videos found
- Uses product image from Shopify

## How Video Picker Works

```python
from video_picker import VideoPicker

picker = VideoPicker(use_youtube=True)

# Pick single video
video = picker.pick_video()
# Returns: Local video OR YouTube video OR None

# Pick multiple (for weekly scheduling)
videos = picker.pick_videos_for_week(count=7)
# Returns: List of videos for 7 days
```

**Priority order:**
1. Check `meeeshop-youtube/videos/` (fastest, no API calls)
2. Check `meeeshop-youtube/output/`
3. Check `meeeshop-youtube/shorts/`
4. If not found, check YouTube channel
5. If nothing found, use product image

## GitHub Actions With Videos

### Workflow Setup

In `.github/workflows/daily-pinterest-posting.yml`:

```yaml
- name: Run daily posting with video support
  env:
    PINTEREST_EMAIL: ${{ secrets.PINTEREST_EMAIL }}
    PINTEREST_PASSWORD: ${{ secrets.PINTEREST_PASSWORD }}
    SHOPIFY_STORE_URL: ${{ secrets.SHOPIFY_STORE_URL }}
    SHOPIFY_ACCESS_TOKEN: ${{ secrets.SHOPIFY_ACCESS_TOKEN }}
    GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}
    GROQ_API_KEY: ${{ secrets.GROQ_API_KEY }}
    OPENROUTER_API_KEY: ${{ secrets.OPENROUTER_API_KEY }}
  run: |
    # Videos automatically picked from repo
    python pinterest_daily.py
```

**How it works in GitHub:**
1. Workflow runs on GitHub's server
2. Clones your repo (including meeeshop-pinterest)
3. Looks for videos in checkout directory
4. Also checks YouTube channel

**For local videos to work:**
- Make sure `meeeshop-youtube` is committed to Git
- Videos in `meeeshop-youtube/videos/` are included
- Workflow can use them

**Resolution:** 1080p or higher

## Troubleshooting

### "No videos found"

**Check:**
1. Are videos in `meeeshop-youtube/videos/`? (or output/shorts/etc)
2. Are they `.mp4`, `.webm`, etc? (not `.txt` or `.md`)
3. Is path correct? `C:\Users\USER\Downloads\Shopify_Claude\meeeshop-youtube\`

**Fix:**
```powershell
# List videos
dir "C:\Users\USER\Downloads\Shopify_Claude\meeeshop-youtube\videos\"

# Move videos to correct location
move "path\to\video.mp4" "C:\...\meeeshop-youtube\videos\"
```

### "YouTube API not working"

**Check:**
1. Is `YOUTUBE_CLIENT_ID` in `meeeshop-youtube/.env`?
2. Is `YOUTUBE_CLIENT_SECRET` set?
3. Is YouTube API enabled in Google Cloud?

**Fix:**
```powershell
# Test video picker
python video_picker.py

# Check what keys are loaded:
# 🔑 Loaded API Keys:
#    ✓ YOUTUBE_CLIENT_ID: ...
```

### "Video posted but looks wrong"

**Check:**
1. Is video format supported? (mp4, webm)
2. Is resolution 1080p or higher?
3. Is aspect ratio correct? (1:1, 4:5, 9:16)

**Fix:**
```powershell
# Convert video to pinterest format
# Using ffmpeg (install: choco install ffmpeg)
ffmpeg -i input.mp4 -vf "scale=1080:1080" -c:v libx264 output.mp4
```

## Performance Tips

### Fast Loading

1. **Use local videos** (no API calls)
   - Faster than YouTube fetch
   - Works offline
   - Instant posting

2. **Batch generate videos** (once per week)
   - Run `youtube_shorts.py` once
   - Creates 5-7 videos
   - Pinterest uses them for 7 days

3. **Organize by date**
   - Newer videos picked first
   - Avoid repetition
   - Chronological posting

### Cost Optimization

1. **Reuse AI keys** from meeeshop-youtube
   - No duplicate API keys
   - Share quota efficiently
   - One .env file per project

2. **Cache video metadata**
   - Script remembers what's posted
   - Avoids re-posting same video
   - Tracks in `posting_history.json`

## Advanced: Schedule Different Content Types

Edit `pinterest_daily.py`:

```python
import calendar

def get_content_type(day_of_week):
    """Different content for different days"""
    video_days = [1, 3, 5]  # Tue, Thu, Sat
    if day_of_week in video_days:
        return "video"
    return "image"

# Use it:
day = datetime.now().weekday()
content_type = get_content_type(day)

if content_type == "video":
    use_video = True
else:
    use_video = False
```
